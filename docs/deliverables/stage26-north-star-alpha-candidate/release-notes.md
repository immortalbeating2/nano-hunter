# Stage26 北极星 Alpha Candidate Release Notes

## 试玩入口

- Godot：`4.6.3`
- 主场景：`res://scenes/main/main.tscn`
- 从主菜单“开始游戏”进入教程；安全首次通关路线自然推进到 Stage16 Alpha 终点。
- Stage11 镇妖驿厅承载悬赏榜与雷泽入口；Stage25 是取得路引后的可回访小区域。

## 候选内容

- 世界图共 `44` 个正式房间、`8` 条远端连接；发现式地图由 JSON 驱动。
- 核心战斗为 `2 元素`（风 / 雷）、`2 姿态`（疾印 / 御印）和两种顺序不同的两步序列。
- Caster、Charger、Seal Guardian 与封印脉冲具有可读元素反应。
- 镇妖驿厅提供 `3 条固定悬赏`，覆盖接取、生产事件追踪、完成、回交和雷泽路引奖励。
- 当前共有 `4 件`圣物 / 组件，任意两件可装备，影响恢复、攻击距离、序列窗口或姿态冷却。
- 雷泽荒原以 `6 房`灰盒形成主路、旧区返回、雷暴危险和风→雷接地小回环。

## 默认控制

- 键盘：移动 `A/D` 或方向键；跳跃 `Space/W/↑`；攻击 `J`；冲刺 `K`；恢复 `L`；元素 `Q`；姿态 `E`；暂停 `Esc`。
- 手柄：游戏内左摇杆 / 十字键移动；A 跳跃；B 冲刺；X 攻击；Y 恢复；LB 元素；RB 姿态；Menu 暂停。菜单内使用左摇杆 / 十字键导航、A 确认、B 返回。
- Xbox Series X Controller 已完成真实 Joypad 事件、InputMap、静置漂移、十字键与教程内运行时响应复核；主观舒适度仍需真人反馈。

## 进度与继续边界

- 同一进程内切房和失败恢复会保留 Main 的能力、悬赏、Build、Boss 与地图发现状态。
- checkpoint 只保存最近房间与出生点。
- “重开 Demo”会回教程并清空本轮状态。
- 当前不支持跨进程继续；主菜单 Continue 只显示这一边界，不存在隐藏存档。

## 已知问题

- `assets/audio/` 尚无运行时音频；攻击、受伤、Boss 预警、机关、UI 与区域氛围均在 P0 / P1 音效缺口清单中。
- 雷泽荒原复用现有美术做冷蓝灰盒，没有独立敌人、区域 Boss 或正式雷泽美术批次。
- 无设置页、键位重绑定、快速旅行、存档槽、随机悬赏、交易经济或商业版多区域体量。
- 真人首次通关、路线理解、Build 手感与实体手柄舒适度不由自动化替代。
