# 2026-07-03 Progress Log

## Luna 全套运行态 body 动作帧 ai03 替换

### 背景

用户要求用 `image_gen` 生成并接入 Luna 当前运行态 body 全套动作帧，替换旧的 ai01 / ai02 混用状态。硬性规格包括透明背景 PNG、不要绿底 / 白底 / 棋盘格、标准规则网格、单动作优先、超过 6 帧多行排布、每帧固定格居中、角色比例 / 视角一致、留白充足、不跨格、不裁切、地面动作脚底稳定、空中动作以身体中心 / 骨盆附近作为视觉锚点。

### 操作

- 使用内置 `image_gen` 生成 `idle`、`run`、`jump_fall`、`attack_body`、`air_dash_body`、`hit_react`、`death_idle` 7 张源图；每张源图按单动作固定网格生成，`hit_react` 使用 `4x2` 多行布局。
- 新增 `scripts/assets/build_luna_unified_runtime_body_sheets.py`，把源图去背景、去网格线、去孤立水平残线并规范化为 `192x192` 固定格透明 PNG；同一动作使用统一缩放比例，地面动作脚底锚定，空中动作身体中心锚定。
- 新增 `luna_*_runtime_sheet_ai03` 的 `.png`、`.png.import`、`.frames.json`、`.source.json`、`.spriteframes.tres`，并生成 `docs/assets/luna-unified-runtime-body-candidates-2026-07-03.json`。
- 更新 `scripts/player/player_placeholder.gd` 与 `scenes/player/player_placeholder.tscn`，将当前运行态 body SpriteFrames 切到 ai03。
- 更新 `tests/stage14/test_stage_14_backtracking_and_ability_gating.gd` 的 Luna 运行态断言，并同步 `capture_luna_attack_vfx_review.gd` / `capture_luna_air_dash_vfx_review.gd` 目标 body 资源。
