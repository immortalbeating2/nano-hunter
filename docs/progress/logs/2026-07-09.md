## Tutorial Room Terrain Template

### 背景

上一轮 `tutorial_room` 仍属于碰撞驱动的视觉试铺：视觉 TileMapLayer 不承担真实地形碰撞，旧 `StaticBody2D` 地面 / 平台 / 墙体仍是权威。用户反馈运行态出现悬空、空气路、空气墙后，本轮改成房间级模板验收：地形和薄平台必须由 `formal_terrain_kit_ai01` TileSet collision 承担权威碰撞；门、背景、装饰、前景保持 visual-only。

### 操作

- 更新 `formal_terrain_kit_ai01` TileSet 生成脚本，把冲刺门上沿 tile 从普通装饰改为 `thin_solid` 碰撞语义。
- 重写 `apply_formal_terrain_kit_tutorial_trial.gd`：生成 `TerrainCollisionVisual`、`PlatformCollisionVisual`、`DoorVisual`、`BackgroundVisual`、`DecorVisual`、`ForegroundVisual` 六层模板。
- 禁用旧地形 `StaticBody2D` 的 collision layer / mask 和 `CollisionShape2D`，但保留节点作为房间元素追溯 bounds。
- 保留 `ExitBarrier`、`ExitZone`、`TutorialDummy` 的独立碰撞和逻辑，不把门控 / 触发 / 敌人塞进 TileMapLayer。
- 修正 TileMapLayer 对齐：地形层改为 `position.y=0`，平台层改为 `position.y=-16`，让 TileSet 内部碰撞面与旧房间 top bounds 对齐。
- 修正窄地面规则：dash 门前后短落点至少铺两格，并用 cap 收边，避免玩家出生点卡在 TileSet 内缩侧边。
- 显式禁用隐藏的 `ShrineTrialTilesetPreview.collision_enabled`；Godot 隐藏 TileMapLayer 不会自动关闭碰撞，该层曾在 dash 门前形成空气墙。
- 新增 `docs/assets/tutorial-room-terrain-elements.md` 和 `docs/implementation-plans/2026-07-09-tutorial-room-terrain-template.md`，记录房间元素清单、TileSet 语义清洗表和下一步边界。

## Tutorial Room 64px Grid Blueprint Demo Layout

### 背景

前两轮虽然把 `tutorial_room` 和 Stage14 gate 的碰撞权威迁到了 TileMapLayer，但用户截图证明视觉仍像零散 tile 拼贴。本轮修正验收口径：`tutorial_room` 不再按旧碰撞块逐段生成地面，而是先固定 64px 网格蓝图，再由脚本按蓝图铺 TileMapLayer，并用网格规则和运行态截图一起验收。

### 操作

- 将 `apply_formal_terrain_kit_tutorial_trial.gd` 改为固定蓝图驱动：主路 `x=-7..15, y=2` 连续 23 格，跳台 `x=-4..-3, y=1` 连续 2 格，dash 门低顶 `x=2..3, y=1`，出口安全落点 `x=10..14, y=2`。
- 保留 `TerrainCollisionVisual` / `PlatformCollisionVisual` 作为地形和薄平台碰撞权威，门、背景、装饰、前景仍 visual-only。
- 退役带格线的 `GroundUnderlayVisual`，新增 `GroundSurfaceVisual` 复用 `shrine_trial_tileset_ai01` 的 left / center / right 地面件作为 visual-only 连续主路视觉，降低主路碎砖感。
- 移除脚本中按每个旧碰撞块自动挂 `support` 的逻辑，避免再次生成柱状 / 悬浮误读。
- 清空本教学房 `DoorVisual` / `BackgroundVisual` / `DecorVisual` / `ForegroundVisual` 的误读 tile，移除左墙重复件、孤立门柱、地面下碎石和漂浮小台座。
- 更新 `test_formal_terrain_kit_tutorial_trial.gd`，直接按网格蓝图验主路连续、平台 cap、dash 门低顶、出口安全落点、GroundSurfaceVisual 和 visual-only 层。
- 更新 `capture_tutorial_collision_driven_terrain_review.gd`，运行态报告新增 `grid_blueprint_ok`、`surface_visual_ok` 与 `ground_underlay_retired`。
