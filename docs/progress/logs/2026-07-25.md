## Alpha Demo 世界地图组成与路线蓝图

### 背景

当前 Stage18 已将 34 房首次通关长链重组为 3 个区域回环和 5 条远端连接，但连接关系分散在场景导出字段、世界图测试和阶段设计文档中，无法快速回答“地图如何组成、路线是否仍是一条线、能力取得后回访哪里”。本轮只整理当前实装事实，不修改运行时连接、关卡碰撞、敌人或门控逻辑。

### 文档

- 新增 `spec-design/2026-07-25-alpha-demo-world-map-blueprint.md`。
- 蓝图包含区域级拓扑、34 个首次通关房间、4 个可选房间、能力 / 奖励解锁顺序和当前设计缺口。
- 新增 `spec-design/images/2026-07-25-alpha-demo-room-route-blueprint.jpg`：以当前 38 张正式房间运行截图为卡片，按真实首次路线和 SC-01 至 SC-05 排布；Stage 仅作为卡片分组，不再作为地图节点。
- 第三方图像 API 只生成无文字、无节点、无路线的东方奇幻制图底板，提示词与确定性合成来源记录在同名 `.prompt.txt`；房间、文字和连线不由图像模型生成。
- 明确区分连接拓扑与尚未冻结的二维物理地图，避免把流程图误当作最终地图 UI 或房间空间坐标。
- 设计结论：当前已经存在三条闭合区域回环，不再是纯单链；但首次安全路线仍是长骨架、Air Dash 取得较晚、早期可选房偏少且缺少地图 UI，因此玩家的线性感受仍然成立。
