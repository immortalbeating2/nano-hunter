## GUT 9.6.1 升级

### 背景

项目已使用 Godot `4.6.3`，本轮将仓库内 vendored GUT 从 `9.6.0` 升级到 `9.6.1`，并确认现有项目内容和测试体系不受补丁升级影响。

### 操作

- 以官方 `v9.6.1` tag（commit `c80954f47bed74a0a2c471d472c0389f98e0a8f6`）的 `addons/gut/` 为来源同步插件。
- 相对原 `9.6.0` 目录更新 `36` 个文件、新增 `9` 个文件，没有删除项；同步官方目录的 `257` 个文件后，仅规范化 `3` 个上游空白行的行尾制表符，不改变运行逻辑。
- 更新 `docs/dev/plugin-inventory.md` 的当前插件版本与验证基线。
- 保留历史日志中的旧版本证据，不修改 `AGENTS.md`；工具版本继续由插件盘点和当日日志维护。

### 验证

- `godot --version`：`4.6.3.stable.official.7d41c59c4`。
- `godot --headless --path . --import`：退出码 `0`；导入前后 Git 可见状态差异为 `0`。
- `godot --headless --path . -s addons/gut/gut_cmdln.gd -gdir=res://tests -ginclude_subdirs -gexit`：运行器报告 GUT `9.6.1`，`33` scripts、`240/240` tests、`6147` asserts，退出码 `0`。
- `godot --headless --path . --quit-after 3`：主场景启动 smoke 退出码 `0`；运行前后 Git 可见状态差异为 `0`。
