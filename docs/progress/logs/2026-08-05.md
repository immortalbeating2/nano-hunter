# 2026-08-05 开发日志

## C2 主菜单生产接入

### 做了什么

- 将用户确认的 C2 重构负空间稿固化为无文字背景 `main_menu_shell_ai02.png`，并生成 / 键控清理独立透明风化字标 `main_menu_wordmark_ai01.png`；两项均保留 source、prompt 摘要、散列和人工发布复核边界。
- `DemoShell` 改为右侧无框响应式菜单：六项同轴居中，使用月灰楷体与符印青实时焦点线；删除常态“已有本地存档”提示和开始 / Continue 图标。
- Continue 仍按存档有效性启用；主档回退备份或双档损坏时不恢复额外提示行，而是在 Continue 文案内显示“备份”或“存档损坏”。暂停、地图、悬赏、Build 和详情面板继续沿用原 NinePatch / 按钮皮肤。
- 修正布局捕获脚本的逻辑视口：每档同时设置窗口与 `content_scale_size`，普通态先把鼠标移出菜单，报告显式验证无残留 hover，再捕获 Start hover。
- 更新 Stage16 / Stage26 / Stage31 回归和 UI / 资产审计。Stage26 手柄用例改用独立测试存档，避免机器默认存档污染焦点预期。

### 为什么

旧菜单在 2K 画面中比例过小，浅色卡片割裂暗色场景，图标列导致标题错位，常态存档提示重复表达 Continue 状态。C2 通过重新分配背景负空间，让菜单成为场景构图的一部分，同时保留真实 Button、焦点与存档门控。

- Stage16：`20/20` tests / `504` assertions；Stage26：`6/6` / `80`；Stage31：`5/5` / `78`。
- 递归 GUT：`48` scripts / `322/322` tests / `8879` assertions；保留既有 ObjectDB orphan / leak 警告，没有失败用例。
- runtime UI binding：`2 scenes / 5 panels / 5 textures`；strict asset package：通过。
- `capture_demo_shell_start_review.gd`：`ok=true`，Start、控制说明 / 返回、开始后隐藏背景、暂停与失败层均成立。
- `capture_demo_shell_layout_hover_review.gd`：`640x360`、`1024x576`、`1672x941`、`2048x1152`、`2560x1080` 五档均 `ok=true`，普通态无 hover，鼠标移入后仅 Start hover。
- C2 参考与 `1672x941` 运行截图完成同像素全图及菜单聚焦比较；`design-qa.md` 最终 `passed`。

## C2 共享动态符光焦点

### 做了什么

- 新增 `main_menu_focus_band.gdshader`，以 `TIME` 连续推动符印青核心线、亮斑、辉光和稀疏符尘；没有生成或烘焙新位图。
- `DemoShell/MainMenu` 新增唯一 `FocusBand`。六个按钮的 hover / focus / pressed StyleBox 移除静态底边，焦点变化只让这一节点以 `0.18s` 缓出 Tween 追踪目标按钮底边。
- 鼠标移入可用按钮时调用真实 `grab_focus()`，因此鼠标、键盘与手柄不会产生两条并存的选中线。
- 布局捕获扩展为同焦点双帧像素采样与 Start → Settings 跨行追踪；`1672x941` 额外保留两帧流动证据和共享光带对照图。
