# 2026-08-28 开发日志

## F03 镇妖驿厅道路、掌柜与悬赏界面修正

### 原因

- F03 的整房背景已经包含正式石板道路，但新灰盒碰撞的显示层与场景遗留 `GroundSurfaceVisual` 仍在下方重复绘制，造成“上下两条路、碰撞像在下面”的错觉。
- 悬赏榜仍受历史 `460×300` 小卡片上限、`16/12px` 字号和无背景暗幕限制，在 2K 画面中正文、头像与滚动区难以辨认。
- 掌柜运行帧与 Luna 的显示单元高度比约 `1.30`，同景深下显得像前景立绘；这批旧帧不能直接视为正式人物资产。

### 执行

- 在共享 `FormalRoomGrayboxLayout` 增加默认开启的 `show_solid_visuals`。其他房间保持原样，只有 F03 关闭灰盒实体地面的重复显示；F03 遗留 `GroundSurfaceVisual` 同步隐藏，碰撞仍由灰盒结构独立承担。
- 将 F03 主碰撞顶面从 `y=224` 上移到背景道路基线 `y=192`，出生点与交互区同步上移 `32u`，相机底边收至 `y=224`；没有用相机裁切替代碰撞对齐。
- 掌柜运行 scale 从 `0.44` 临时调整为 `0.34`，先满足与 Luna 接近的同景深体量；正式替换需求登记为 `NS28-WaystationClerkFinal`，本轮不生成新资产。
- `DemoShell.DetailPanel` 改为按视口约 `42%×56%` 响应式布局，增加全屏暗幕，提高标题/正文/按钮字号，悬赏与 Build 条目改成两行并保留现有滚动、焦点和按钮皮肤。
- F03 左上目标缩短为“确认驿厅通路 / 左返 / 右进”，并以 Label 的真实渲染行数保护两行容量；悬赏榜交互测试补上真实 `ui_down`，不再依赖残留输入状态。
