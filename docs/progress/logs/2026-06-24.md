## Animation Runtime Replacement Pass ARP-17 - Active Candidate / Archived Reference Audit Split

### 背景

为了避免后续继续把旧失败样本误读为当前开发阻塞，本轮把动作替换候选审计拆成两个口径：

- 活跃 runtime candidates：参与 strict gate，必须几何 / 资源门禁通过。
- 归档 references：保留证据与重生成依据，不参与 active blocker 数字，但必须声明 `superseded_by`，并由审计确认替代资产存在。

  - 新增 `--include-archived` 选项，默认 strict gate 只审计活跃候选。
  - 新增 `audit_archived_references(...)`，检查归档参考是否声明 `superseded_by`，并确认替代资产 ID 或目标路径存在。
  - 报告新增 `active_asset_count`、`archived_reference_count`、`archived_reference_error_count` 与 `Archived References` 表。
- 更新 `docs/assets/animation-runtime-replacement-candidates.json`：
  - `luna_air_dash_runtime_sheet_ai01` 标记为 `superseded_reference`，替代项为 `luna_air_dash_body_runtime_sheet_ai02` 与 `stage14_air_dash_trail_ai01`。

- 重写 `docs/assets/animation-runtime-replacement-candidate-audit-report.json` 与 `.md`。
- 更新本实施计划、`status.md` 与 `timeline.md`，把当前口径改为 `15/15 active ready`、`0 active blocked`、`8 archived references`、`0 archive errors`。
