## Stage19 发现式地图美术与可维护性重构

### 原因

用户运行图证明原 `WorldMapView` 虽然功能正确，但五行蛇形、小矩形节点、直线和 `900x620` 小窗仍是工程调试图，不满足正式类银河恶魔城地图读值。

### 实现

- 使用 Codex built-in Image Generation 生成 `stage19_discovery_map_base_ai01.png`：只含宣纸、黑漆铜框、莲纹和非语义水墨环境；生成后的视觉母版单独保存为 `spec-design/images/2026-07-28-stage19-discovery-map-visual-reference.png`，没有运行时引用。
- 新增 `assets/configs/world_map/alpha_demo_world_map.json`，把 `38` 房、五区域归属、归一化坐标、34 房安全路线、4 支路和 SC-01 至 SC-05 从脚本常量移出。
- `WorldMapView` 改为从 JSON 绘制五区域星座：房间使用佛龛 / 符印形状，主路与支路使用弧形墨线，远端连接使用金色断续弧线，相邻未知房显示墨雾空印，当前房显示古金 + 青白双环。
- DemoShell 保持底板宽高比并按视口扩展；房间位置、路线或区域变化只需修改 JSON，不需要重生成图片或改绘制器。

- 全局 source safety 严格审计通过：`134` candidates、当前地图底板 `1` 个 `project_session_confirmed`、`0 unsafe`。
- 资产包 strict 审计同步接受当前队列数量并通过：`56` queue items、`56` provenance records、`0 unsafe`；Stage17 资产处置回归 `12/12` / `156` asserts。
