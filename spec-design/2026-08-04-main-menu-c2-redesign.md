# C2 主菜单正式设计

## 目标

以用户确认的 C2 方向替换当前小型羊皮纸主菜单：背景左侧保留月、禁地门、锁链与符印细节，右侧以低细节雾区承载可交互菜单。主菜单必须像场景的一部分，而不是覆盖在场景上的独立卡片。

选定参考：`assets/source/ai_generated/batch_08/main_menu_shell_ai02/candidates/main_menu_shell_ai02_c2_selected.png`。

运行背景：`assets/art/ui/main_menu_shell_ai02.png`；独立字标：`assets/art/ui/main_menu_wordmark_ai01.png`。

## 视觉契约

- 使用无面板的右侧纵向结构；菜单中心位于 16:9 画面约 `74%` 宽度处。
- 标题固定为 `NANO HUNTER`；六项入口保留开始、继续、选关、设置、控制说明、退出。
- 文字使用月灰 / 蓝灰；焦点、悬停和按下态只使用一条符印青光带及轻微提亮，不显示按钮矩形底板。
- 六项按钮共用唯一 `FocusBand`：CanvasItem Shader 以 `TIME` 持续推动亮斑、辉光与稀疏符尘，节点本身只负责平滑追踪当前焦点按钮底边；不得退回每个按钮各画一条静态边框。
- 删除主菜单状态提示和开始 / 继续前置图标；Continue 是否可用仍由现有存档状态控制。
- 背景与交互层分离：背景图片不得烘焙标题、菜单文字或选中线；字标可使用独立透明纹理，六项菜单和焦点状态必须保持 Godot 实时控件。

## 响应式与交互

- `640x360` 至 `2560x1440` 保持六项完整可读、同轴居中且不越界。
- 16:9 采用 C2 右侧安全区；21:9 保持右侧菜单，不把面板重新移回画面中心。
- 键鼠与手柄焦点链、开始 / Continue / 详情页 / 返回行为保持原契约。
- 鼠标移入可用入口时同步为真实 UI 焦点；键盘、手柄和鼠标因此共用同一条光带与同一焦点状态。光带移动使用短促缓出，不改变 Shader 内部持续流动，也不使用闪烁。

## 非目标

- 不重做暂停、地图、悬赏、Build 或详情面板。
- 不改变存档格式、房间流程和输入映射。
- 本轮用户选型只批准 C2 主菜单方向；商业发布授权、跨平台字体回退与最终审美签核继续保留人工门禁。
