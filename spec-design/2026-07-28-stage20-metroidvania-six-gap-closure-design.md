# Stage20 六类银河城缺口闭环设计

## 文档定位

本阶段回应 Stage19 明确留下的六类缺口：早期第二支路、第二类环境危险、Caster 职责深化、第二能力交叉门控、奖励 Build 深度和正式剧情事件。

目标不是把 Alpha Demo 扩成完整商业版技能树、装备库或剧情系统，而是让六项各自形成一个可试玩、可回访、能互相回流的最小闭环。现有 `room_transition_requested`、`receive_attack(...)`、探索奖励字典、HUD 快照和暂停详情面板继续作为唯一契约。

## 闭环总览

```text
Stage9 Switch ──普通主路──> Stage9 Final ──> Stage10 Aerial
      │                                           │
      └──早期替代支路──> Stage10 Branch ─────────┘
                              │
                              └──取得风印

风印：攻击可斩散 Caster 弹体
风印 + Air Dash：Stage13 Gate <──SC-06──> Stage14 Air Dash Gate

Stage13 Resource：瘴泽遗物 Build
Stage13 Challenge：镇妖挑战符 Build
暂停菜单：在已取得的两件圣物间切换调谐

Stage11 中央封印：触发一次正式剧情事件
```

## 六项设计结论

### 1. 早期第二支路

- 复用 `Stage10 Branch`，不新增空房。
- `Stage9 Switch -> Stage10 Branch -> Stage10 Aerial` 改为首次流程即可选择的替代路线。
- 原安全主路 `Stage9 Switch -> Stage9 Final -> Stage10 Aerial` 保留。
- 支路以现有空中敌、秘密墙、恢复点和收集物承担探索价值；收集物升级为第二能力“风印”。
- 这条路线允许跳过 Stage9 Final，但不跳过 Stage10 Challenge、Stage11、Stage15 Boss 或 Stage16 终局链。

### 2. 第二类环境危险

- 新增“封印脉冲阵”，与静态瘴气区分：
  - 瘴气：进入危险区后造成一次伤害，强调空间绕行。
  - 封印脉冲：休止、预警、激活循环，强调时机通过。
- 首批只放在 `Stage10 Challenge` 与 `Stage14 Air Dash Gate`，不向所有房间批量撒陷阱。
- 使用 Godot `Area2D`、矩形碰撞和现有色彩语言，不新增位图资产。

### 3. Caster 职责深化

- 保留触碰伤害与压力光环，新增真实定向弹体。
- Caster 只在玩家进入 `projectile_range` 后按配置间隔施法。
- 弹体造成一次伤害、达到最大距离后消失，可被已解锁风印的玩家攻击斩散。
- 单 Caster 房承担弹体教学，双 Caster 房自然形成交叉火力，不新增第 5 类普通敌人或弹幕框架。

### 4. 第二能力交叉门控

- 第二能力固定为“风印”：
  - 探索作用：作为 SC-06 的一半条件。
  - 战斗作用：让普通攻击能命中并斩散敌方弹体。
- SC-06 连接 `Stage13 Gate <-> Stage14 Air Dash Gate`，要求“风印 + Air Dash”。
- 新玩家无需 SC-06 也可完成主线；能力门只提供回访捷径，不跳过 Air Dash 获取。

### 5. 奖励 Build 深度

- 不新增背包、装备孔位或技能树。
- 现有两件 Stage13 持久奖励成为可调谐 Build：

| Build | 效果 | 主要价值 |
| --- | --- | --- |
| `marsh_relic` 瘴泽遗物 | 恢复充能获取量 `x1.5` | Boss / 高压房容错 |
| `warden_sigil` 镇妖挑战符 | 攻击判定横向延伸 `16px` | Caster 弹体与多高度接敌 |

- 首件取得的圣物自动调谐；两件都取得后，暂停菜单按钮在已取得 Build 间循环切换。
- Main 保存当前调谐，换房后重新注入玩家；重开 Demo 清空。

### 6. 正式剧情事件

- Stage11 中央封印首次确认时触发一次暂停式剧情事件。
- 事件内容同时推进三件事实：
  1. 瘴泽灾变来自地方官员私运妖骨，而非单纯天灾。
  2. 镇妖卫悬赏刻意隐去百姓名册。
  3. 陌生妖声察觉 Luna 的同源气息，第一次触碰佛妖混血主线。
- 复用 `DemoShell.DetailPanel`，显示标题、正文和“继续”按钮；不建立通用对话树、头像系统或分支选项。
- Main 按事件 ID 去重并进入进度快照；重开 Demo 后可再次触发。

## 状态与数据边界

Main 新增并持有：

- `wind_seal_unlocked`
- `active_build_id`
- `completed_story_event_ids`

Player 只接收：

- 风印是否解锁
- 当前 Build ID

世界地图配置新增 SC-06，并把所有远端连接的可用条件写入 JSON `requirements`；地图视图按 Main 快照通用判断，不再为新连接追加 ID 硬编码。

## 视觉与碰撞规则

- 封印脉冲碰撞只存在于 `Area2D`，不改变正式 TileMap 地形。
- 脉冲预警与激活必须使用不同透明度，激活碰撞与可见带保持同尺寸。
- Caster 弹体使用现有腐瘴警示 VFX 资源，碰撞半径保持小于可见核心。
- SC-06 出生点使用现有安全平台，不落在出口或 ShortcutZone 触发半径内。

## 验收标准

1. Stage9 首次流程存在两条从 Switch 到 Aerial 的可选路线，主路与支路都可达。
2. 两个正式房间包含循环式封印脉冲危险，预警期不伤害、激活期只结算一次。
3. Caster 能在范围内生成真实弹体；无风印攻击不能命中弹体，有风印时可斩散。
4. SC-06 在缺少任一能力时关闭，同时拥有风印与 Air Dash 后双向开放。
5. 两件 Stage13 奖励产生不同玩家效果，暂停菜单可在已取得 Build 间切换，换房保持、重开清空。
6. Stage11 首次确认显示一次剧情面板并记录事件；继续后恢复游戏，同轮不重复触发。
7. Stage18 / 19 旧世界图契约同步更新；Stage20 专项、邻近测试、全量 GUT、Godot import、主场景 smoke 和运行态复核取得新鲜证据。

## 非目标

- 不实现 2 元素 + 2 姿态 + 2 步序列核心战斗切片。
- 不实现技能树、装备栏、存档持久化、任务系统、对话分支或剧情编辑器。
- 不新增房间、敌人类别、货币、Boss 阶段或正式美术批次。
- 不把风印扩展成独立按键、法力资源或多招式系统；当前只验证探索与弹体反制的双重价值。
