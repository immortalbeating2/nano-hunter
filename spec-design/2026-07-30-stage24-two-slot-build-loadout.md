# Stage24 两槽圣物 / 组件 Build 设计

## 目标

把 Stage20 的单件圣物循环升级为两槽轻量选择，让 Stage21 / 22 的元素序列与姿态在同一轮 Demo 内形成可组合差异。

## 固定内容

| ID | 名称 | 来源 | 唯一效果 |
| --- | --- | --- | --- |
| `marsh_relic` | 瘴泽遗物 | Stage13 资源支路 | 恢复充能获取 `x1.5` |
| `warden_sigil` | 镇妖挑战符 | Stage13 挑战支路 | 横向攻击距离 `+16px` |
| `caster_core` | 腐瘴法珠 | 回交“断瘴缉术” | 两步元素序列窗口 `+0.75s` |
| `guardian_core` | 守印金刚心 | 击败 Seal Guardian | 姿态切换冷却 `-0.15s` |

## 装备规则

- 最多同时装备两件；同一 ID 不能重复。
- 新取得物品在有空槽时自动装备，槽满后只进入可选列表。
- 详情面板允许卸下已装备物品或装备未使用物品；槽满时不暗中替换，先提示玩家卸下一件。
- `active_build_id` 保留为当前调谐焦点，兼容 Stage20 单按钮读值；实际效果由两槽列表决定。
- 装备和已取得列表跨房保留，`restart_demo()` 全部清空；本阶段不实现正式存档。

## UI

- 暂停菜单的“圣物”按钮打开现有 DetailPanel。
- 复用 Stage23 已有滚动选择列表和按钮皮肤，显示四件已取得物品的装备状态与单一效果。
- 不新增背包页、拖放、稀有度、强化、套装或数值比较器。

## 状态边界

- Main 保存已取得列表、两槽装备列表和调谐焦点，并输出稳定快照。
- Player 只接收两槽 ID；恢复、攻击范围、序列窗口和姿态冷却继续在既有公开计算入口生效。
- Caster / Boss / 房间不读取装备状态，只通过现有事件授予组件。

## 验收

- 四件物品均能通过既有生产事件取得。
- 任意两件可装备，第三件在槽满时不能越界进入。
- 两件效果可以同时生效并跨房保留。
- 暂停面板可读地完成查看、卸下和装备。
- 重开清空已取得与装备状态，Stage20 单件接口保持兼容。

## 非目标

- 不做物品栏、装备树、强化、合成、随机词条、货币或存档。
- 不新增伤害数值体系、敌人种类或 Boss 阶段。
