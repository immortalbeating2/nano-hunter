# Stage22 敌人与 Boss 元素反应设计

## 目标

让 Stage21 的两步序列改变既有敌人、危险与 Boss 的真实结果，而不是只改变 HUD、判定盒和击退数字。

## 最小战斗循环

1. 玩家观察 Caster 余弹、Charger 冲锋、Boss 预警或封印脉冲。
2. 用普通攻击维持原有通关方式，或在 `2.0s` 内组织指定两步序列。
3. 序列命中后直接复用对象已有的击败、硬直、动画和危险相位反馈。

## 唯一命中入口

- Player 仍以 `receive_attack(...)` 作为最终伤害入口。
- 只有需要读取 Stage21 上下文的对象实现可选 `receive_elemental_attack(...)`；默认实现必须立即委托原 `receive_attack(...)`，不得建立第二套生命或伤害框架。
- 上下文只包含当前元素、姿态和本次已冻结的序列反应；换房和下一次攻击不保留目标侧临时上下文。

## 四个反应

### Caster：追击破法

- `wind -> thunder` 命中时，Caster 仍按原规则被击败。
- 同时斩散房间内仍存活的腐瘴弹，形成比普通击败更安全的反制结果。

### Charger：散射破势

- `thunder -> wind` 命中时，立即取消读招 / 冲锋，并沿命中方向产生一次可见退位。
- 随后仍走 BaseEnemy 原击败契约，不增加生命条或新状态机。

### Seal Guardian：预警破印

- 只在 `close_pressure` 预警窗口接受 `wind -> thunder` 破印。
- 本次命中照常扣 `1` 点生命，但直接清空剩余护印并进入既有 `staggered`；其它状态保持普通命中。

### 封印脉冲：错峰

- `thunder -> wind` 的第二击为风元素，沿用 Stage20 已有 Area2D 攻击查询。
- 命中脉冲阵后回到完整休止段，关闭当前预警 / 激活视觉并错开下一轮节奏；普通风击不改变相位。

## 状态与反馈

- Caster / Charger / 脉冲随房间重建清空。
- Boss `reset_boss()` 清空反应结果并恢复既有生命、护印和状态。
- 反馈复用腐瘴弹消失、Charger 退位与 defeat、Boss stagger、脉冲视觉关闭，不新增正式资产。

## 非目标

- 不增加元素伤害倍率、异常状态栈、元素抗性表或通用效果框架。
- 不重做普通敌人生命系统，不增加 Boss 阶段、招式或新敌人。
- 不改变普通攻击、风印斩弹、两姿态和失败恢复的既有通关语义。

## 退出标准

- Player 的真实命中能把 Stage21 上下文送到可选反应入口。
- Caster、Charger、Seal Guardian、封印脉冲四类对象均有可观察差异。
- 普通命中仍保持旧契约；Stage22 专项、邻近战斗、全量 GUT、Godot import、smoke 和运行态复核通过。
