# Stage23 镇妖驿站与悬赏榜设计

## 目标

把 Stage11 镇妖驿厅升级为“接榜 -> 探索 / 战斗 -> 回驿厅回交 -> 获得情报”的最小可玩循环，并让状态进入 Main 快照、HUD、暂停与地图读取边界。

## 悬赏榜交互

- Stage11 中央新增可见 `BountyBoardZone`；玩家靠近后打开现有 DetailPanel。
- DetailPanel 动态显示三个固定按钮，不新增通用任务页、对话树或随机任务。
- `available` 按钮执行接取，`completed` 按钮执行回交；`accepted` 与 `turned_in` 只读显示当前状态。
- 离开悬赏榜再靠近才能重新打开，避免关闭面板后同帧反复弹出。

## 三个固定悬赏

| ID | 标题 | 完成条件 | 回交奖励 |
| --- | --- | --- | --- |
| `caster_hunt` | 断瘴缉术 | 接取后击败任一 Miasma Caster | 瘴泽术式记录 |
| `demon_bone_evidence` | 妖骨取证 | 取得 Stage13 资源支路的 `marsh_relic` | 妖骨案卷 |
| `seal_pulse_cleanup` | 封印错峰 | 用雷→风使任一封印脉冲回到休止段 | 雷泽荒原路引 |

- 三项全部回交后解锁 `waystation_intel_unlocked`，作为 Stage25 雷泽荒原入口情报，不建立可消费货币。
- 普通击败、探索奖励和封印脉冲反应仍由原系统结算；悬赏层只观察已批准事件。

## 状态归属

- Main 保存 accepted / completed / turned-in 三组 ID，跨房、失败、暂停和地图保留。
- `restart_demo()` 清空全部悬赏状态、回交记录和驿站情报；本阶段不实现正式存档。
- 只在已接取状态下响应 Caster 与封印脉冲事件；妖骨取证接取时可根据已取得的 `marsh_relic` 立即同步为可回交。

## 展示

- HUD 的现有提示行在存在已接悬赏时显示“已接 / 完成 / 回交”计数，不额外扩大 BattlePanel。
- 世界图快照携带悬赏计数与驿站情报，但地图仍只负责显示和暂停，不写任务状态。
- 悬赏榜正文说明操作，按钮显示“接取 / 追踪中 / 回交 / 已回交”和奖励名称。

## 非目标

- 不做随机悬赏、计时任务、赏银经济、商店、物品兑换、任务导航箭头或通用任务数据库。
- 不启用 Dialogue Manager，不加入新 NPC、正式存档或新资产批次。
- 不改变 Stage11 左返 / 右进、checkpoint、一次性剧情事件和 Stage16 完成语义。

## 退出标准

- 三项悬赏都可独立接取，且至少一条真实走完接取、完成、回交和奖励。
- Caster、`marsh_relic`、封印脉冲三条生产事件能推进对应悬赏，未接取时不推进。
- 暂停 / 地图不改状态，Stage11 完成不等于 Alpha 完成，重开清空。
- Stage23 专项、邻近回归、全量 GUT、Godot import、smoke 和运行态复核通过。
