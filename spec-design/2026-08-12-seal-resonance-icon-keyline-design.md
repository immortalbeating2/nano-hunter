# 符印共鸣盘图标 Keyline 与像素门禁设计

**状态：** 用户已批准方案 A，并于 2026-08-12 对最终干净图符的正反序列实机截图回复“可以”；本文件冻结实现与验收门槛。该回复只关闭本轮截图级造型、清晰度与屏幕阅读效果，不代表物理显示距离、来源授权或 Gate26H 通过。
**范围：** 只修复右侧符印共鸣盘的六枚动态图标、五个 active 语义槽位、idle 两个槽位及其反馈动画；不重生 FrameArt，不改变元素 / 姿态 / 序列玩法。

## 1. 问题与根因

现有门禁把 `TextureRect` 的矩形中心当成图标中心。六枚 AtlasTexture 虽然共用 `256x256` 单元格，但实际 Alpha 轮廓的质心与外径差异很大；因此控件矩形可以精确落在圆框中心，图案仍会视觉偏心或越圈。元素反馈还会把整个图标向右平移 `4px`，使静态对齐在动画中失效。

本轮采用方案 A：图标源统一到一个可测量的光学半径，运行态只按五个语义圆心布局，圆形 Shader 仅作为异常资产的安全遮罩。用户复核进一步证明最大径向 keyline 会被细长尖端钻空子，因此机器门禁必须同时读取实际 Alpha 核心的 95% 分布半径与等效墨量，不能再用控件矩形或最远尖端代替视觉内容。

## 2. 六图标源合同

- Atlas 固定为 `768x512`，`3x2`，每格 `256x256`；语义顺序仍为 `wind / thunder / swift / ward / wind_thunder_pierce / thunder_wind_scatter`。
- Alpha 核心阈值固定为 `16`；低于阈值的抗锯齿与微光不参与核心几何判定。
- 每格以 Alpha 权重质心作为该符号的可复算视觉焦点，构建后目标为 `(128,128)`。
- 质心误差必须 `<= 0.5px`。
- 光学半径定义为 `sqrt(r95 × sqrt(alpha_weight/pi))`：`r95` 是累计 95% Alpha 权重的半径，`alpha_weight` 是核心像素 Alpha 总量。目标固定为 `60px`，允许 `57–63px`。
- 最远 Alpha 核心半径只作为安全 keyline，必须 `<=104px`，不能再作为图标视觉大小。
- 六枚源图两两光学比必须位于 `0.96–1.04`；相同圆框使用相同图标尺寸后应读取为等大。
- 任意 Alpha 核心像素不得触碰 `256x256` 单元格边界；六格不得互相污染。
- 微型 HUD 不允许用金属颗粒、暗描边或刻蚀噪声表达材质：以 `Alpha>=96`、相对亮度 `<=0.12` 查找被主体四向包围的 `1–2px` 暗连通块，源格与 Lanczos 缩到 `29px / 34px` 后允许数量都固定为 `0`。
- `29px / 34px` 微缩样本的 Alpha 边缘平均对比必须 `>=0.18`。这一项只拒绝糊边，不要求最近邻采样；斜线与弧线继续使用线性运行采样，避免以锯齿换“锐”。
- 构建只允许：固定等格裁切、Alpha 核心质心测量、一次等比缩放、亚像素平移居中、透明底合成。不得非等比拉伸、逐图手绘修补或改变语义顺序。

## 3. 五语义圆心与运行尺寸

圆心继续沿用已批准 FrameArt 原生测量；`circle_inner_radius` 是从黑色显示井到金属内缘的保守半径。图标控件使用内圆直径，标准化后的实际 Alpha 只占约 `79.69%` 半径，从而形成一致留白。

| 状态 | 角色 | 逻辑圆心 | 内圆半径 | 图标控件 |
| --- | --- | ---: | ---: | ---: |
| idle | `element` | `(64.75, 51.25)` | `30px` | `60x60` |
| idle | `stance` | `(144.75, 53.25)` | `18px` | `36x36` |
| active | `element` | `(58.50, 54.00)` | `31px` | `62x62` |
| active | `stance` | `(140.25, 55.75)` | `19px` | `38x38` |
| active | `sequence_a` | `(158.00, 124.50)` | `14.5px` | `29x29` |
| active | `sequence_b` | `(216.25, 124.50)` | `14.5px` | `29x29` |
| active | `reaction` | `(287.00, 126.00)` | `17px` | `34x34` |

运行态冻结门槛：

- 节点变换计算得到的图标焦点到目标圆心误差 `<= 0.5` 逻辑像素；此门槛不受屏幕像素取整影响。
- glyph-only 最终实机栅格必须同时满足 Alpha 核心质心误差 `<= 0.8` 逻辑像素与 `<= 1.25` 物理像素。双单位门槛用于约束低分辨率缩小与高 DPI 放大后的离散采样，不能只通过其中一项。
- 映射到任一槽位后，落在 `circle_inner_radius - 2px` 之外的 Alpha 核心像素必须为 `0`。
- `sequence_a / sequence_b` 的最终栅格光学比必须位于 `0.94–1.06`；`reaction` 对两枚序列印均值的最终光学比在 `1x` 及以上视口必须接近 `34/29`，冻结区间为 `1.10–1.23`。低于 `1x` 的 `640/1024` 视口受 27px 级离散采样影响，但仍不得小于 `1.05`。
- 圆形安全遮罩的归一化半径固定为 `0.49`、羽化宽度 `0.01`；正常资产不得依赖遮罩裁掉核心像素才能通过。
- `疾印 / 御印` 等文字保持在信息区；文字矩形与相邻圆框外缘的最短距离必须 `>= 8px`。

## 4. 动效合同

- 核心图标不允许位置 Tween；普通与 reduced-motion 模式的语义焦点都必须保持在同一圆心。
- 元素反馈只允许透明度与以圆心为 pivot 的 `0.94 → 1.03 → 1.0` 缩放；任一采样帧仍须满足变换焦点 `<=0.5px`，并通过上述最终实机双单位像素门槛与圆内核心门槛。
- 姿态反馈可保留以圆心为 pivot 的 `0.86 → 1.0` 缩放与 `-0.08 → 0` 旋转，不允许平移。
- reduced-motion 只保留换图、颜色与透明度变化。

## 5. 三层验证

1. **源资产门禁：** strict 审计复算六格 Alpha 质心、95% 分布半径、等效墨量、光学半径、最大安全半径、边界像素、源级暗斑、`29/34px` 暗斑与边缘对比、来源记录。
2. **运行变换门禁：** GUT 验证五圆心、图标尺寸、圆形 Shader、文字间距及动画全过程不平移。
3. **实机像素门禁：** 七档视口正常合成截图之外，再输出透明背景 glyph-only 证据；逐槽复算最终渲染 Alpha 质心、圆内留白和越界像素。质心必须同时通过 `0.8` 逻辑像素与 `1.25` 物理像素两项门槛，防止任一缩放方向掩盖偏移。

任何一层失败都不得写作“视觉通过”。三层机器门禁通过只形成运行技术候选；本轮最终正反序列实机截图已获得用户视觉签核，物理观看距离、授权与 Gate26H 仍需单独确认。
