# 正式 Demo 房间设计重构规格

## 文档定位

本设计取代“把现有 44 房全部视为正式 Demo 房间并继续局部修补”的方向。用户已批准采用方案 B：保留现有切房、战斗、能力、存档和世界图基础，把正式 Demo 收敛为 `15–18` 个精心设计的房间；其余房间保留为候选、沙盒或后续扩展，不删除、不继续冒充正式主路线内容。

本阶段是关卡设计重构，不是房间切换系统重写。继续复用：

- `room_transition_requested`
- `checkpoint_requested`
- `get_hud_context()`
- Main 的跨房完成态、能力态、探索奖励与 v1 存档
- 现有玩家、敌人、Boss、HUD、地图与驿站契约

## 当前问题判断

当前工程已经证明 `44` 房可加载、可连接、可保存、可回访，且房间地形视觉与碰撞大体一致；这些证据只说明技术骨架可靠。

房间设计仍存在五个结构性问题：

1. `34` 房首次路线仍是一条长链，大部分非线性来自远端连接，不来自房间簇自身的空间选择。
2. 多批房间由“连续地板 + 少量短平台 + 同背景缩放 + 出口坐标”生成，空间轮廓和移动节奏高度相似。
3. 清场、能力、剧情和普通切房经常共享门或屏障表现，户外环境出现缺少建筑与玩法理由的实体门。
4. 自动测试主要保护固定坐标、格数、碰撞和连接，不能证明三秒读路、回访价值、节奏波动或探索欲望。
5. 既有 `44/44` 房间职责矩阵是内容目录，不是玩家行为验收；“写明职责”不等于“空间已经表达职责”。

因此当前整体成熟度判断为：

- 房间切换与状态系统：技术候选。
- 宏观世界图：局部 L2。
- 单房与房间序列：整体 L1，少量能力房接近 L2。
- 正式 Demo：未达到 L2，不进入发布或继续扩图阶段。

## 正式 Demo 的目标体验

目标玩家在没有设计师讲解、没有攻略、仅有现有基础 UI 的情况下，能够在 `30–45` 分钟内完成一条包含教学、驿站、区域探索、能力获取、回访、捷径、高潮战与返回 Hub 的完整循环。

玩家必须能够回答：

- 我从哪里来，下一步大致去哪？
- 这个障碍为什么现在不能通过？
- 新能力改变了哪些旧地点？
- 支路的风险与回报有什么差异？
- 我打开的捷径具体节省了什么？
- 为什么这里需要门、结界、落差或传送？

- `goal_trial_room`：功能并入 F02，保留为兼容和回归样本。

- Stage13 `crossfire`、`pressure`、`return`：分别与 F05、F06、F09/F12 职责重复，保留为后续变体来源。
- `stage14_loop_return_room`：回环职责并入 F15。
- `stage15_seal_pressure_room`、支路 D：有价值的敌人和危险组合并入 F11/F16。
- Stage16 五房：保留终局封印链，不纳入 30–45 分钟纵向切片。
- Stage25 六房：保留为后续雷泽扩展区；当前美术和 Boss 可继续作为候选，但不以平直六房结构代表正式第二生态区。

退出主路线不等于删除，也不立即破坏旧存档。正式路由切换前必须提供旧房路径回退到 F03 或最近有效入口的兼容策略。

## 正式路线与循环

```text
F01 教学
  -> F02 首次实战
  -> F03 镇妖驿站
  -> F04 区域入口
  -> F05 风印与弹体
  -> F06 瘴气上下路线
  -> F07 Air Dash 门预告
  -> F08 检查点
  -> F09 三路枢纽
       |-> F10 低风险资源 -> F08
       |-> F11 高风险挑战 -> F12
       `-> F12 正常主路
  -> F13 Air Dash 神龛
  -> F14 能力证明
  -> F15 回访集结
       -> 回到 F06 / F07 / F09 取得新路线价值
       -> F16 综合战斗
       -> F17 Boss
       -> F18 战后返回
       -> F03 镇妖驿站
```

正式切片包含三类循环：

1. `F09 -> F10 -> F08 -> F09`：低风险资源回环。
2. `F07 <-> F14/F15`：风印 + Air Dash 打开的永久捷径。
3. `F03 -> 区域 -> F18 -> F03`：完整悬赏循环。

## Air Dash 的三个旧地点重构

Air Dash 不能只用于一个测试缺口。获得后至少重新解释三个已见地点：

1. F06：跨越下层瘴气，取得原本只能看见的奖励并形成高速线。
2. F07：与风印共同解除交叉能力门，连接 F14/F15，形成主要永久捷径。
3. F09：进入上层路线，缩短主路并打开挑战支路的反向入口。

F07 是主线所需捷径；F06 与 F09 提供可选收益。玩家不取得可选奖励也不能软锁。

## 单房设计合同

每个正式房间必须记录并在场景中表达：

- `1` 个主要职责；
- `0–2` 个次要职责；
- `1` 个空间记忆点；
- 首次路线；
- 能力后回访路线；
- 熟练玩家快速路线；
- 每个入口的安全观察区；
- 正向和反向镜头读值；
- 失败后的重试距离；
- 出口的环境语义；
- 支路成本与奖励；
- 需要保留的持久状态。

普通房间进入后三秒内应看见安全落点、主要方向、最近危险，以及支路或暂不可达区域中的至少一项。

## 移动标尺与空间等级

正式布置前先以生产 Player 测量：

- 最大与舒适水平跳距；
- 最大与舒适垂直跳高；
- Dash、Air Dash 距离与结束速度；
- 空中控制与落地停距；
- 土狼时间和输入缓冲；
- 攻击位移、受击击退；
- 玩家碰撞体和镜头提前量。

以实测极限为 `100%`：

| 用途 | 建议使用比例 |
| --- | ---: |
| 安全教学 | `40–60%` |
| 普通主线 | `55–75%` |
| 常规挑战 | `70–85%` |
| 高难可选 | `85–95%` |

普通落脚平台至少为角色宽度 `1.5–2` 倍；教学落点至少 `2` 倍。超过 `95%` 的操作不得出现在首次主线。

## 出口与门的语义规则

`ExitZone` 是逻辑触发器，不自动拥有门的视觉。

| 连接含义 | 表现 | 是否需要实体门 |
| --- | --- | --- |
| 相邻户外空间 | 山口、断桥、洞口、坡道、雾幕边界 | 否 |
| 普通室内房间 | 与建筑结构连续的门洞或门扇 | 可选 |
| 清场限制 | 由敌人维持的妖气结界，清场后消散 | 不使用通用门扇 |
| 永久能力门 | 统一符印、瘴幕、断层或不可达高台 | 是，但必须表达所需能力 |
| 单向连接 | 落差、塌陷、井道、滑道 | 否 |
| Boss入口 | 唯一的重型封印建筑 | 是 |
| 远端连接 | 驿站、祭坛、传送机关 | 是，且不能伪装成相邻房间门 |

正式切片中通用 `GateBarrier/BarrierArt` 只允许保留在 F02、F07、F14、F16、F17 等确有状态理由的房间，并按语义替换外观；普通出口不得复用同一门框。

## 区域视觉与地标

灰盒通过前不新增正式背景。灰盒通过后再为瘴泽建立：

- `2–3` 个跨房可识别的大地标；
- F04 区域入口轮廓；
- F08 恢复地标；
- F09 分叉地标；
- F13 神龛焦点；
- F17 Boss 封印建筑。

同区域可共享材质与色彩，但不得用同一张完整背景只改变缩放来代表不同房间。背景装饰不能冒充平台、门或可破坏墙。

## 遭遇与节奏

房间序列采用波浪：

```text
低压建立 -> 教学 -> 常规压力 -> 恢复 -> 分支选择
-> 目标 -> 能力授予 -> 能力测试 -> 回访 -> 综合战斗
-> Boss -> 降压返回
```

- F05 只教学风印与弹体，不同时承担高强度混战。
- F06 以环境危险为主，不额外堆敌。
- F08、F13、F18 保持安全。
- F11 和 F16 承担高强度普通遭遇。
- F17 失败后 `10–25` 秒内重新进入可操作 Boss 阶段。

## 自动与真人验收

### 自动门禁

- `18/18` 正式房存在且可实例化。
- 连接、目标 spawn、返回 spawn 和地图展示一致。
- 所有入口出生在安全地面且不与出口触发器重叠。
- 正反向切房、失败恢复、Continue 和旧存档兼容。
- F06/F07/F09 的能力前后路径状态正确。
- 普通出口没有无语义通用门；保留门控均有明确类别。
- 可踩视觉与碰撞继续一致。

### 真人灰盒门禁

- 新玩家无讲解完成 `30–45` 分钟切片。
- 普通房 `5` 秒内识别主方向的玩家比例至少 `80%`。
- 切房后不可避免受伤 `0` 次。
- 普通主线跳跃两次内成功率至少 `90%`。
- 获得 Air Dash 后至少 `70%` 玩家想起一个旧障碍。
- 至少 `70%` 玩家不依赖文字提示发现主要永久捷径。
- 强制回访耗时比首次路线降低至少 `30%`。
- 持续无收益迷失超过 `90` 秒不多于 `1` 次。
- 玩家能描述驿站、瘴泽分岔和 Air Dash 神龛三个主要地标。

自动通过不能代替真人门禁。没有新玩家数据时，只能称为“灰盒技术候选”。

## 非目标

- 不重写房间加载为连续世界或流式加载。
- 不新增完整技能树、经济、任务链或第二个正式生态区。
- 不立即删除退出正式路线的 `26` 个房间。
- 不在移动标尺与五房微循环通过前生产全套正式美术。
- 不以截图唯一哈希、路线自动通关或 GUT 全绿宣称房间达到 L2。
